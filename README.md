# 📋 HighwayWorkD

**แอปจัดการงานโครงการทางหลวง**

แอปพลิเคชันสำหรับบันทึก ติดตาม และจัดการงานโครงการทางหลวง ออกแบบมาให้ใช้งานง่ายบนมือถือและคอมพิวเตอร์ รองรับการติดตั้งเป็นแอป Progressive Web App (PWA)

---

## ✨ ฟีเจอร์หลัก

- 📋 **รายการโครงการ** - จัดการโครงการทางหลวงหลายแห่ง
- 📊 **แดชบอร์ดภาพรวม** - ดูสถิติและความก้าวหน้างานทั้งหมด
- 📝 **บันทึกความก้าวหน้า** - บันทึกงานรายวันและสถานะการดำเนินงาน
- 📸 **แกลเลอรีรูปภาพ** - เก็บรูปภาพงานและหลักฐานการปฏิบัติงาน
- 📤 **ส่งออกรายงาน** - สร้างรายงานเพื่อการนำเสนอหรือเก็บข้อมูล
- 📱 **รองรับ PWA** - ติดตั้งเป็นแอปบนมือถือ ใช้งานออฟไลน์ได้

---

## 🚀 วิธีเริ่มต้นใช้งาน

### วิธีที่ 1: เปิดผ่านเบราว์เซอร์
1. ดาวน์โหลดหรือ clone repository นี้
2. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์
3. เริ่มใช้งานได้ทันที

### วิธีที่ 2: รันด้วยเซิร์ฟเวอร์ (แนะนำสำหรับ PWA)
```bash
# ใช้ Python
python3 -m http.server 8000

# แล้วเปิดเบราว์เซอร์ที่ http://localhost:8000
```

### วิธีที่ 3: ติดตั้งเป็นแอปบนมือถือ
1. เปิดเว็บไซต์ผ่านเบราว์เซอร์ Chrome หรือ Safari
2. กดเมนู **"เพิ่มไปยังหน้าจอหลัก"**
3. แอปจะปรากฏบนหน้าจอโทรศัพท์พร้อมใช้งาน

## 🛠️ เทคโนโลยีที่ใช้

- **HTML5** - โครงสร้างหน้าเว็บ
- **CSS3 / Tailwind CSS** - การออกแบบและสไตล์
- **JavaScript (Vanilla)** - โค้ดประมวลผลหลัก
- **LocalStorage / IndexedDB** - เก็บข้อมูลภายในอุปกรณ์
- **PWA (Progressive Web App)** - รองรับการติดตั้งและออฟไลน์
